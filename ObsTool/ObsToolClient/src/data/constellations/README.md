# Constellation Map Data

`constellations.bounds.json` and `constellations.lines.json` are vendored from
`ofrohn/d3-celestial`:

- https://github.com/ofrohn/d3-celestial
- https://raw.githubusercontent.com/ofrohn/d3-celestial/master/data/constellations.bounds.json
- https://raw.githubusercontent.com/ofrohn/d3-celestial/master/data/constellations.lines.json

The source repository publishes the data as GeoJSON in degrees, with longitude
in `[-180, 180]` and latitude in `[-90, 90]`.
